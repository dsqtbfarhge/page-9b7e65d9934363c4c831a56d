01 / 服务概览

一份订阅，对应一组节点

Stashbox 将节点配置封装为单一订阅链接，导入兼容的客户端后即可在多平台使用。订阅内的节点、流量与设备上限随套餐档位调整，按月或按年刷新。

// 01

订阅链接交付

完成订阅后获得一条可复制的链接，导入客户端后自动同步节点信息，更新节点时无需重复配置。

// 02

多设备配额

同一订阅可在套餐允许的设备数量内同时在线，便于在手机、电脑与平板之间切换使用。

// 03

月度流量计量

每月按套餐档位提供固定的可用流量额度，超出部分按所选套餐规则处理，可在工单内查询明细。

02 / 使用步骤

从订阅到上线的四个步骤

以下流程描述了 Stashbox 订阅从选购到在客户端中生效的一般顺序，具体客户端操作以对应软件说明为准。

  1. 选购套餐并获取订阅链接

    在订阅套餐区域选择合适的月付或年付档位，完成支付后系统会展示一条以 https 开头的订阅地址。

  2. 在客户端中添加订阅

    打开兼容的代理客户端，进入订阅或配置页面，将上述链接粘贴至订阅地址栏并保存。

  3. 更新节点列表

    在客户端中触发一次订阅更新，节点列表会按当前套餐内容刷新，并按设备上限生效。

  4. 选择节点并启用

    从节点列表中选中可用节点，开启系统代理或按客户端指引启用本地代理，即可开始使用。

订阅链接示例

实际链接由服务后台生成，下方仅为格式示意：

https://example.com/sub?token=xxxxxxxx

请将整段地址复制到客户端的订阅项中，避免截断或包含多余空格。

05 / 常见问题

订阅、流量与设备相关问题

以下为选购与使用 Stashbox 订阅过程中较常遇到的问题，具体工单处理结果以服务后台答复为准。

订阅

订阅链接在哪里查看？

完成支付后，订阅链接会显示在订单详情页面以及用户中心的订阅项中，整段以 https 开头，可直接复制使用。

流量

每月流量是如何计算的？

流量按自然月重置，以客户端实际产生的上行与下行总和为准，统计周期与所选套餐的计费方式一致。

设备

超过设备上限会怎样？

同时在线的设备数量超过套餐上限时，最早接入的设备会被自动下线，可在客户端中重新登录恢复使用。

计费

月付和年付可以切换吗？

在订阅有效期内可切换计费方式，未使用的月付余额按比例折算，年付到期前会按当时价格续费，可在到期前关闭自动续费。

节点

节点列表什么时候更新？

节点信息会不定期调整，每次更新后可在客户端中手动触发订阅更新，已保存的本地配置不会被覆盖。

支持

遇到问题如何联系？

可通过用户中心的工单入口提交问题，旗舰版与团队版享受优先处理顺序，工作日内通常会有较快响应。
